# Zen Next

Experimental next-generation model research.

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

## Overview

Zen Next is the experimental research track for next-generation Zen models. This repository hosts preview weights, architecture experiments, and bleeding-edge techniques being evaluated for future Zen releases.

| Property | Value |
|----------|-------|
| Status | Experimental |
| License | Apache 2.0 |

## Notice

Models in this repository are research previews. They may change without notice and are not recommended for production use. For stable models, see the main [Zen model family](https://github.com/zenlm/zen-family).
